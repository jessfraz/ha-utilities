# Utilities

Read-only utility bills, balances, collection events, and meter intervals for
Home Assistant. Waste Management and Bayou are native adapters; SQLite keeps
the reconciled local read model used by the dashboard, CLI, and Assist.

## Run

In Home Assistant, use the app's Configuration options for explicit account,
service, deployment, and currency bindings, plus the WM/Bayou password fields.
No file editor or SSH is needed. Native installations can use
[the fictional TOML example](config/example.toml) with runtime credential-file
paths. Keep credentials in 1Password and runtime storage, never source control.

```sh
utilities --config /data/config.toml --database /data/utilities.sqlite3
ha-utilities --token-file /data/api-token providers list
ha-utilities --token-file /data/api-token bills list --limit 25 --json
fetch-home-assistant ha-utilities --transport home-assistant summary --json
```

HA transport uses `HOME_ASSISTANT_URL` and `HOME_ASSISTANT_TOKEN`. Native uses
`UTILITIES_URL` and `UTILITIES_TOKEN_FILE`. Explicit `--url` and `--token-file`
override those settings; `ha` remains a transport alias.

The server creates a private API-token file on first startup. Native clients
use bearer authentication; the browser uses an HTTP-only session. The HA app
uses admin-only Supervisor ingress. `/openapi.json` is generated by Dropshot
from the Rust types, also available with `utilities --openapi PATH`.

Add this repository to the HA app store and install the bundled
`custom_components/utilities` integration. It supplies a collection calendar,
sensors, guarded Energy statistics, redacted diagnostics, Repairs, and
explicitly exposed read-only Assist tools. Native HA cold backups own recovery.

[Provider contracts and limits](PROVIDERS.md) explain coverage. No payment,
booking, account enrollment, or utility-account modification exists here.
Provider access is not established merely by installing this app. Empty,
partial, unavailable, and stale data remain distinguishable.

## Develop

`nix develop --command scripts/check` runs Rust, SQLite query-plan, HA, and
real-browser checks. All bundled examples and test data are fictional.
